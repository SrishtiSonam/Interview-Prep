# Complete AI-Powered Career Development Platform

A comprehensive platform designed to transform your career journey from learning to landing your dream job. It combines AI-powered tools with structured learning paths to provide everything you need for career success.

---

## 🚀 Platform Overview

### **Step 0: Understanding Through Visualization** 📊
- **Interactive Learning Visualizations**: Master complex topics through step-by-step visual representations
- **DSA Learning & Visualizer**: Data Structures and Algorithms with interactive visualizations
- **Concept Mapping**: Visual understanding of programming concepts and problem-solving approaches
- **Real-time Feedback**: Get instant visual feedback on your learning progress

### **Step 0: Project Preparation & ML Application** 🤖
- **CSV Data Processing**: Prepare and understand datasets for machine learning applications
- **Data Preprocessing Tools**: Clean, transform, and prepare data for ML models
- **Feature Engineering**: Learn to extract meaningful features from raw data
- **Model Preparation**: Understand the complete ML pipeline from data to deployment

### **Step 1: Resume & CV Enhancement** 📝
- **AI Resume Builder**: Generate ATS-optimized resumes with the highest visibility scores
- **Resume Evaluator**: Upload your resume and job description for matching scores and improvement suggestions
- **Cover Letter Generator**: Create tailored cover letters using your resume, job description, and role information
- **ATS Optimization**: Ensure your resume passes through Applicant Tracking Systems

### **Step 2: Interview Preparation & Assessment** 🎯
- **Targeted MCQ Generation**: Practice questions based on specific job descriptions and levels
- **Progress Tracking**: Monitor your performance and track improvement over time
- **AI Interviewer**: Practice with our AI-powered interview simulator
- **Technical Interview Prep**: Comprehensive preparation for technical interviews
- **Aptitude Testing**: Practice aptitude questions and problem-solving skills

## ⚙️ Installation Guide

1. **Clone the repository**:
   ```bash
   git clone 
   ```

2. **Backend Setup**:
   ```bash
   cd server
   python -m venv env
   
   # Activate virtual environment
   # Windows:
   .\env\Scripts\activate
   # macOS/Linux:
   source env/bin/activate
   
   pip install -r requirements.txt
   ```

3. **Frontend Setup**:
   ```bash
   cd ../frontend
   npm install
   ```

---

## Running the Platform

1. **Start the Backend Server**:
   ```bash
   cd server
   python main.py
   ```

2. **Start the Frontend**:
   ```bash
   cd frontend
   npm run dev
   ```

3. **Access the Platform**:
   - Frontend: `http://localhost:5173`
   - Backend API: `http://localhost:8000`

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS, Vite
